# Brand artwork

Files in this folder are served as `/brand/<name>`.

| File | Used for | What it should be |
| --- | --- | --- |
| `radog.png` | The placeholder behind a product with no photo | The French bulldog head, black line art on white or transparent, about 400-800 px |

If `radog.png` is missing the till draws a built-in silhouette instead.
